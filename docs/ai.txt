## 一句话摘要
跃界 HopWorld 是 macOS 原生可视化代理客户端（SwiftUI），面向 VNP/代理节点管理：多协议导入、测速、按国家连接、规则/全局/分应用 TUN；基于 Xray 与 sing-box，开源 MIT。

## 产品关键事实
- 名称：跃界 / HopWorld
- 平台：macOS 13.0+
- 协议：VLESS、VMess、Trojan、Shadowsocks、Hysteria2、MASQUE、TUIC、AnyTLS、WireGuard、SOCKS5、HTTP（11 种）
- 能力：软路由（局域网 HTTP 17890 / SOCKS5 17891，其它设备不必再装代理 App，不改本机主连接）、订阅测速、国家一键连接、规则/全局/分应用 TUN、应用连通探测、Codex / Cursor / Claude 用量、Codex 重置提醒、失效节点与临时文件清理
- 版本：v2.0.0（2026-11-12 DMG）
- 下载：Apple Silicon / Intel DMG（ad-hoc 签名，未做 Apple 公证）
