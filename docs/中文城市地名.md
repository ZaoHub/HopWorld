# 中文城市地名

首页、国家页和节点列表共用同一套城市解析。原始城市和运营商名称保留在节点数据及悬停说明中。

## 数据与匹配

- 随应用提供 `ChineseCities.json`，源于 [GeoNames](https://www.geonames.org/) 的 cities500 和带语言标记的 alternateNamesV2 数据。
- 2026-10-25 快照包含 42,080 条中文地名和 214,143 个检索别名，约 10.2 MB。只保留存在中文名的城市、人口聚居地及少量注明来源的校正记录，并不覆盖全球所有小镇。
- 结合出口国家、行政区及坐标缩小候选，再优先匹配规范名称和官方首选英文名。同名且无法消除歧义时不猜测结果。
- 括号区域说明不会阻止匹配主城市。繁体名称在显示前转换为简体。
- 数据按 CC BY 4.0 使用，应用“关于”页和随包 `GeoNames-LICENSE.txt` 提供署名与许可链接；源文件校验值记录在快照中。

## 后台补查与缓存

离线库未命中、出口接口同时提供有效坐标时，后台尝试 Apple 的中文逆地理编码。只提交出口地理坐标，不提交节点 IP、端口或代理凭证，也不获取用户设备当前位置。

查询串行执行，同一地点并发请求合并，单次查询四秒超时；临时失败十分钟内不重复请求。成功结果写入节点加密存储和本地中文地名缓存，退出后仍可使用。出口信息变化时，旧查询结果不会覆盖新节点信息。退出应用时停止节点更新任务。

后台查询不参与连接成功或测速成功的判断。它失败、超时、只返回英文，或者没有有效坐标时，城市栏显示“中文名待补充”；原始城市缺失则显示“未知”。运营商继续采用可靠中文别名，缺少中文名称的品牌保留原名，ASN 不翻译。

## 更新快照

从 https://download.geonames.org/export/dump/ 下载 `cities500.zip`、`alternateNamesV2.zip`、`admin1CodesASCII.txt` 到同一临时目录。原始压缩文件约 220 MB，不提交到项目、不随应用分发。

```sh
python3 Scripts/update_chinese_cities.py --source-dir /tmp/hopworld-geonames --version 2026-10-25
```

脚本只使用 Python 标准库。重新生成后运行 `ChineseCityCatalogTests` 和 `NodeExitMetadataTests`，验证数据随应用及测试包正常复制、典型城市、同名歧义、缓存、超时和旧数据兼容。
