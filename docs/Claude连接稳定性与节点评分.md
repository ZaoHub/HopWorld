## Claude 专项证据

Claude 官方 Messages API 使用 SSE 传输流式事件；正常消息由 `message_start` 开始、`message_stop` 结束，期间可能出现 `ping` 或 `error` 事件。HTTP 200 后仍可能发生流内错误。因此这里的 Claude 长连接指标定义为“流式响应完整率”，不能只检查 HTTP 状态、收到首字或连接在线时长。[官方流式文档](https://platform.claude.com/docs/en/build-with-claude/streaming)、[官方错误说明](https://platform.claude.com/docs/en/api/errors)。

此定义针对官方 Messages API。Claude 网页、桌面客户端、Claude Code 及第三方网关需按实际后端和协议单独验证，不能从一次官网探测推断所有客户端的行为。现有应用连通检测收到 401/403/429 等有效 HTTP 响应时，最多说明收到了响应；不证明账号、地区、额度或流式生成功能可用。

## 评分设计（100 分）

采用与 Codex 相同的网络权重和初始阈值，专项稳定性证据独立定义。未知项不赋分，不将低覆盖度分数放大成 100 分。

| 维度 | 权重 | 定义及初始公式 | 当前状态 |
| --- | ---: | --- | --- |
| Claude 流式响应完整率 | 35 | 完整结束的有效 SSE 请求数 / 有效 SSE 请求数；需解析正常结束及流内错误 | 未采集，不由 HTTPS 探测代替 |
| 真实丢包 | 15 | `max(0, 1 - loss / 0.05)` | 已提供共享 STUN UDP 往返缺失实测，不由请求失败率或 TCP 重传率代替 |
| 延迟抖动 | 15 | `max(0, 1 - jitterMs / 300)`；相邻成功 HTTPS 总耗时差的绝对值均值，失败断开相邻序列 | 复用通用网络样本 |
| HTTPS 请求成功率 | 20 | 设置中测试地址的成功请求数 / 已完成请求数 | 复用通用网络样本，不是 Claude 生成成功率 |
| P95 延迟 | 15 | `clamp(1 - max(0, P95ms - 200) / 1800, 0, 1)` | 复用通用网络样本，不是 Claude 首字延迟 |

未运行专项时，当前基础分最多覆盖 50%，例如“50 / 50（覆盖 50%）”。运行有效的 [UDP 专项实测](WebSocket与UDP专项实测.md) 后 Claude 最多覆盖 65%，WSS 参考观测不会冒充 Claude SSE 证据。两种场景共用基础样本，因此当前基础分相同是预期行为。Claude 流式完整率及 TCP 重传仍显示“未观测”；UDP 显示本轮实际发送/回包数量和往返缺失率，预检未通过则显示“未验证”。分数暂不参与自动优选。

## 未来专项采集与归因规则

以下是专项设计，本次没有接入真实 Claude 流式采集器。有效样本必须固定节点、目标、模型、超时和并发，并记录客户端类型；API、网页和网关的结果分别统计。

| 观测 | 记录方式 | 评分与归因 |
| --- | --- | --- |
| 流式完整性 | 记录开始、首个内容事件、结束、流内错误、EOF/reset 和总时长 | 收到正常结束且无流内错误才算完整；`max_tokens`、`tool_use` 等正常停止原因本身不算网络失败 |
| 中途断开 | 没有正常结束事件便收到 EOF/reset 或明确网络读写错误 | 标为中断候选；和本地网络变化、节点核心退出及服务端错误对照后归因 |
| 首字慢 / 长时间无文本 | 区分建连/TLS、首个事件、首个内容、后续事件间隔；单独记录服务端 ping | 首字慢和文本间隔可能受模型计算/思考影响，不直接扣节点网络分；SSE 不能套用 WebSocket ping/pong 检测 |
| 401 / 403 | 记录状态码及错误类型，不保存请求/响应正文 | 单列认证/访问限制，不直接定为节点断线；不能仅凭状态码区分全部原因 |
| 429 | 单列限流/额度相关现象 | 不直接推断节点并发限制；与账号/目标限流对照 |
| 529 / overloaded_error | 记录 HTTP 或流内错误类型、时间与请求关联标识 | 单列服务端过载；不能定为节点丢包。HTTP 200 后的流内错误也必须识别 |
| 主动停止 / 本机睡眠或离线 | 明确标为用户取消或本地网络事件 | 不混入节点流式完整率的有效样本；保留单独计数 |
| 出口变化 / 高峰退化 | 沿用现有出口观测，未来按同节点、不同时段对照 | 第三方出口检测不一定等于 Claude 实际出口；只能提出拥堵、出口池或周期中断候选原因 |

明确识别为认证、访问、限流、服务端过载或用户取消的样本，单独统计，不混入节点网络完整率的分母。未能归因的中断保留“原因未知”，不能自动指定服务商故障。未来实现采集器时需测试这些排除规则，目前评分模型只接收已整理好的有效存活比例。
