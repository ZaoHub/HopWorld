# 跃界 iOS 1.0.0

iPhone / iPad 版跃界，可导入订阅或分享链接、管理节点和订阅组、测试延迟并通过系统 VPN 连接。应用内置 sing-box 内核。

最低目标系统为 iOS 13.0。本次版本曾在 iPhone 13 Pro、iOS 16.1.2 上由用户实机使用；iOS 13 等其他系统版本尚未完成真机验证。

## 安装

本版本提供用于 TrollStore 的 IPA。请确认设备和系统版本受 [TrollStore](https://github.com/opa334/TrollStore) 支持，通过 TrollStore 安装 IPA；更新时使用相同方式覆盖安装。此包不需要每七天使用个人 Apple ID 重新签名。普通免费 Apple ID 重签可能移除 VPN 所需权限，不适用于该安装包。

首次连接时按系统提示允许添加 VPN 配置。订阅和节点包含敏感信息，分享问题截图或日志时请先遮挡订阅链接和节点凭据。

## 已知限制

- iOS 13 是构建目标，但尚未在 iOS 13 设备上测试。当前构建环境为 Xcode 27，编译时临时关闭了 SDK 最低部署版本诊断；这不代表该 SDK 官方支持 iOS 13。
- 测速要求选择的所有测试目标均可访问，延迟取最慢结果。节点、网络和不同协议的表现仍需实际测试。
- iOS 的系统 VPN 不支持像 macOS 客户端那样按应用设置代理。

## 内核和源码

安装包包含静态链接的 sing-box / Libbox，遵循上游许可证；跃界自有源码遵循仓库中的 MIT 许可证。发布二进制前应核对并提供与所用内核及第三方依赖完全对应的源码、修改和许可证。当前构建使用本机提供的 Libbox，仓库不包含该二进制依赖。
