# 跃界 iOS 1.0.1

相对 1.0.0 的更新。最低目标系统仍是 iOS 13.0。主 App 与 VPN 扩展的版本均为 1.0.1（构建号 6）。

2026-11-17 打包的 `HopWorld-iOS-1.0.1-TrollStore.ipa` 已通过真机架构构建、ad-hoc 签名和 IPA 完整性检查。这个安装包尚未在手机上安装验证。

SHA-256：`8457c166affa29621f5f661ab629e70f794df3c8be2c8380c392559a24b80e4a`

## 更新

- 订阅可以改名称和地址。已有订阅组可以追加分享链接，也可以删除其中的节点。
- 测速可以勾选多个目标，全部成功才算可用，延迟取最慢一项。可以从本机已安装的第三方 App 里选择，并检测 App 自己的服务器；也可以添加自定义网址。
- 可以按国家限制可连接的节点，只使用测速可用的节点，或要求先测到出口地址。连接超时后会自动换到下一个仍符合条件的节点。
- 批量测速结束且当前未连接时，会询问是否连上测到的节点。
- 节点域名在交给 sing-box 之前先用系统 DNS 解析，避免部分域名被公共 DNS 返回失败。
- 订阅详情可以显示服务商公告和账户信息。
- 增加主题设置。点空白处可以收起键盘。

## 安装

本版本提供用于 TrollStore 的 IPA。请确认设备和系统版本受 [TrollStore](https://github.com/opa334/TrollStore) 支持，通过 TrollStore 覆盖安装。此包不需要每七天使用个人 Apple ID 重新签名。

首次连接时按系统提示允许添加 VPN 配置。

## 已知限制

- iOS 13 是构建目标，但尚未在 iOS 13 设备上测试。当前构建环境为 Xcode 27，编译时临时关闭了 SDK 最低部署版本诊断。
- 测速要求选择的所有测试目标均可访问，延迟取最慢结果。
- iOS 的系统 VPN 不支持像 macOS 客户端那样按应用设置代理。
